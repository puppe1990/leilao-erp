# leilao-erp Financeiro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `leilao-erp`, a mini ERP on Cais for auction resale, starting with full finance: lots/items cost allocation, mixed-channel sales, cash, payables, receivables, and dashboard — seeded with 22 monitors at R$603.

**Architecture:** Domain-first on Cais (Go + Inertia/Svelte + SQLite). User records business facts (lot purchase, sale); cash entries and AP/AR titles are derived. Money is always integer centavos. Auth is single-user session now; signup disabled in production.

**Tech Stack:** Cais CLI (`cais`), Go 1.22+, gonertia, Svelte 5, Tailwind, SQLite (`modernc.org/sqlite`), Vitest for Svelte pages.

**Spec:** `docs/superpowers/specs/2026-07-27-leilao-erp-financeiro-design.md`

```go
package domain

import (
	"fmt"
	"strconv"
	"strings"
)

func FormatBRL(cents int64) string {
	neg := cents < 0
	if neg {
		cents = -cents
	}
	reais := cents / 100
	cent := cents % 100
	s := fmt.Sprintf("R$ %d,%02d", reais, cent)
	if neg {
		return "-" + s
	}
	return s
}

func ParseBRLToCents(s string) (int64, error) {
	s = strings.TrimSpace(s)
	s = strings.TrimPrefix(s, "R$")
	s = strings.TrimSpace(s)
	s = strings.ReplaceAll(s, ".", "")
	s = strings.ReplaceAll(s, ",", ".")
	if s == "" {
		return 0, fmt.Errorf("empty amount")
	}
	f, err := strconv.ParseFloat(s, 64)
	if err != nil {
		return 0, err
	}
	// round to nearest cent
	return int64(f*100 + 0.5), nil
}

func SaleNet(gross, fee, shipping int64) int64 {
	return gross - fee - shipping
}

func Margin(net, unitCostAtSale int64) int64 {
	return net - unitCostAtSale
}
```

- [ ] **Step 5: Implement allocate**

```go
package domain

// AllocateUnitCosts splits totalCents across qty items.
// First (totalCents % qty) items get floor+1; rest get floor.
// Returns nil if qty <= 0.
func AllocateUnitCosts(totalCents int64, qty int) []int64 {
	if qty <= 0 {
		return nil
	}
	base := totalCents / int64(qty)
	rem := int(totalCents % int64(qty))
	out := make([]int64, qty)
	for i := 0; i < qty; i++ {
		out[i] = base
		if i < rem {
			out[i]++
		}
	}
	return out
}
```
